# GH-600 — Test me later

The Certification Learning Coach adds short reminders here when a GH-600 topic,
question style, prerequisite, or misconception deserves another look. This is
a learning queue, not a scorecard or a completion record.

- Issues versus pull requests: distinguish tracking a problem from reviewing a proposed change, including a proposed requirements document; revisit how an agent fits into each step.
- Agent evaluations: design a scenario and observable success criteria for detecting focus drift, then explain how to assess a proposed instruction change without assuming one successful run proves reliability.
